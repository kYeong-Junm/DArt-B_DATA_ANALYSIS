# 1️⃣ 개념 정리 

## 01. 데이터 분석이란

: 유용한 정보를 발견하고 결론을 유추하거나, 의사 결정을 돕기 위해 데이터를 조사, 정제, 변화 모델링하는 과정

## 02. 구글 코랩과 주피터 노트북

• 구글 코랩: 클라우드 기반, 패키지 모두 제공, 코랩 파일 = '노트북' 

• 주피터 노트북: 설치 필요, 패키지 직접 설치

## 03. 이 도서가 얼마나 인기가 좋을까요?

• 공개 데이터 세트: 기업이나 정부 등이 무료로 공개하는 데이터 세트

• CSV 파일: 콤마(,)로 구분된 텍스트 파일. 한줄이 하나의 레코드이며, 레코드는 콤마로 구분된 여러 필드 혹은 열로 구성됨.

• 판다스: 표 형식 데이터를 위한 편리한 도구를 다양하게 제공하는 데이터 분석 패키지. CSV나 엑셀 파일을 읽거나 쓸 수 있음.
