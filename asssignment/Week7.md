## 01. 통계적으로 추론하기

> 분석 대상 데이터를 모두 수집하기 어려울 때 **샘플 데이터로 전체에 대한 통계량을 추론**하거나 가설을 검증함.

## 모수검정과 표준점수

### 모집단과 표본

- **모집단(population)**: 관심 대상이 되는 전체 데이터
- **표본(sample)**: 모집단에서 선택한 일부 샘플
- **모수검정(parametric test)**: 모집단의 **파라미터(평균, 분산 등)**를 표본으로 추정하는 방법
- 모수검정은 보통 모집단이 **정규분포**를 따른다는 가정을 전제로 함 (정규분포: 평균을 중심으로 좌우 대칭, 종 모양)


### 표준점수(z 점수)

각 값이 **평균에서 표준편차의 몇 배만큼 떨어져 있는지**를 나타낸 점수. 단위가 다른 데이터(몸무게 kg, 키 cm)도 같은 기준으로 비교 가능.

```
z = (x - μ) / σ
```

### 누적분포

- **표준정규분포**: 평균 0, 표준편차 1인 정규분포 (이때 z = x)
- z 점수 **±1 이내 ≈ 68%**, **±2 이내 ≈ 95%**

| 메서드 | 기능 | 예시 |
|---|---|---|
| `stats.norm.cdf(z)` | z 점수 **이하**의 누적 비율 | `norm.cdf(0)` → 0.5 |
| `stats.norm.ppf(비율)` | 누적 비율에 해당하는 **z 점수** (cdf의 반대) | `norm.ppf(0.9)` → 1.28 |

```python
stats.norm.cdf(1.0) - stats.norm.cdf(-1.0)   # 0.6827 (±1 이내 비율)
stats.norm.cdf(2.0) - stats.norm.cdf(-2.0)   # 0.9545 (±2 이내 비율)
```

---

## 중심극한정리

**"무작위로 뽑은 표본들의 평균은 정규분포에 가깝다"** 는 이론. 모집단이 정규분포가 아니어도 성립함.

- 모집단에서 n개를 뽑아 평균을 구하는 과정을 반복 → 그 **평균들의 분포**가 정규분포를 따름
- 대출건수 열 자체는 한쪽으로 심하게 치우쳐 정규분포와 거리가 멀지만, 표본 평균의 히스토그램은 종 모양에 가까워짐

```python
np.random.seed(42)
sample_means = []
for _ in range(1000):
    m = ns_book7['대출건수'].sample(30).mean()    # 30개 샘플링 후 평균
    sample_means.append(m)
plt.hist(sample_means, bins=30)
```

- 샘플링 크기가 **클수록** 모집단 평균에 가까워짐. 일반적으로 **30 이상**이면 중심극한정리를 따르기 좋음 (일종의 매직 넘버)

### 표준오차(standard error)

표본 평균의 표준편차. **모집단 표준편차를 표본 크기의 제곱근으로 나눈 값**과 가까움.

```
표준오차 = σ / √n        (n: 표본에 포함된 샘플 개수)
```

---

## 신뢰구간 — 모집단 평균 범위 추정

**신뢰구간(confidence interval)**: 표본의 파라미터(여기서는 평균)가 속할 것이라 믿는 **모집단의 파라미터 범위**. 표본이 하나뿐이어도 모집단 평균의 범위를 추정할 수 있음.

**파이썬 도서 추출** — 주제분류번호가 '00'으로 시작(컴퓨터 관련)하고 도서명에 '파이썬' 포함

```python
python_books_index = ns_book7['주제분류번호'].str.startswith('00') & \
                     ns_book7['도서명'].str.contains('파이썬')
python_books = ns_book7[python_books_index]
len(python_books)                                   # 251권
python_mean = np.mean(python_books['대출건수'])      # 14.749
```

**공식 유도** — 모집단 평균을 모를 때 표본 평균에 대한 z 점수:

```
z = (x̄ - μ) / (σ/√n)    →    μ = x̄ - z × (σ/√n)
```

- 모집단 표준편차(σ)를 모르므로 **표본의 표준편차로 대체**한 뒤 표준오차를 계산

```python
python_std = np.std(python_books['대출건수'])
python_se = python_std / np.sqrt(len(python_books))   # 0.804 (표준오차)
```

**95% 신뢰구간의 z 점수** — 양쪽 꼬리가 각각 2.5%이므로 0.975와 0.025를 `ppf()`에 입력

```python
stats.norm.ppf(0.975)   #  1.96
stats.norm.ppf(0.025)   # -1.96 (정규분포는 대칭이라 부호만 다름)

print(python_mean - 1.96*python_se, python_mean + 1.96*python_se)
# 13.17  16.33
```

> 💡 해석: "파이썬 도서의 모집단 평균 대출건수가 **13.2~16.3 사이에 있다고 95% 확신**한다."

---

## 가설검정

**가설검정(hypothesis test)**: 표본 정보를 사용해 **모집단의 파라미터에 대한 가정을 검정**하는 것.

| 가설 | 기호 | 의미 |
|---|---|---|
| **영가설(귀무가설)** | H₀ | 표본 사이에 통계적으로 의미 있는 차이가 **없다** (μ_python − μ_C++ = 0) |
| **대립가설** | Hₐ | 표본 사이에 통계적인 차이가 **있다** (μ_python − μ_C++ ≠ 0) |

**두 모집단의 평균에 대한 z 점수**

```
z = ((x̄₁ - x̄₂) - (μ₁ - μ₂)) / √(σ₁²/n₁ + σ₂²/n₂)
```

- 영가설에서는 μ₁ − μ₂ = 0으로 놓고 z 점수를 계산
- 이 z 점수가 일정 수준 이하면 → "평균 차이가 없는 데이터가 관측될 가능성이 매우 낮다" → **영가설 기각, 대립가설 채택**
- **유의수준(significance level)**: 기각 기준. 일반적으로 정규분포 양쪽 꼬리 면적의 합이 **5%**가 되는 지점
- **p-값**: 양쪽 꼬리 면적의 합. **p-값 < 0.05이면 영가설 기각**

### z 점수로 가설 검증 (파이썬 vs C++)

```python
cplus_books_index = ns_book7['주제분류번호'].str.startswith('00') & \
                    ns_book7['도서명'].str.contains('C++', regex=False)   # '+'는 정규식 특수문자
cplus_books = ns_book7[cplus_books_index]       # 89권, 평균 11.6
cplus_se = np.std(cplus_books['대출건수']) / np.sqrt(len(cplus_books))   # 0.975

z = (python_mean - cplus_mean) / np.sqrt(python_se**2 + cplus_se**2)     # 2.495
stats.norm.cdf(2.50)      # 0.9938
```

- 양쪽 끝 면적 = (1 − 0.994) × 2 ≈ **0.01 < 0.05** → 영가설 기각, "파이썬과 C++ 도서의 평균 대출건수에 차이가 있다"는 대립가설 지지

### t-검정 — `ttest_ind()`

- **t-분포**: 정규분포와 비슷하나 중앙이 조금 낮고 **꼬리가 더 두꺼움**. 표본 크기가 30 이하일 때 사용하면 좋고, 30보다 크면 정규분포와 거의 같아짐 → 표본 크기에 상관없이 사용 가능
- `ttest_ind()`: 두 표본의 평균을 비교해 **t 점수와 p-값**을 반환 (t 점수는 정규분포의 z 점수에 해당)

```python
t, pvalue = stats.ttest_ind(python_books['대출건수'], cplus_books['대출건수'])
print(t, pvalue)     # 2.139  0.0332  → p-값 < 0.05, 영가설 기각
```

> ⚠️ z 점수나 t-검정은 모두 **모집단이 정규분포를 따른다는 가정** 하에서 수행하는 모수검정.

## 순열검정 — 정규분포가 아닐 때

**순열검정(permutation test)**: 모집단이 정규분포를 따르지 않거나 분포를 알 수 없을 때 사용. 모집단의 파라미터를 추정하지 않으므로 **비모수검정(nonparametric test)**의 하나.

**원리**
1. 두 표본의 평균 차이를 계산
2. 두 표본을 **섞은 뒤** 원래 표본 크기와 동일하게 무작위로 두 그룹으로 나눔
3. 나눈 두 그룹의 평균 차이를 다시 계산
4. 이 과정을 여러 번 반복해, 원래 평균 차이가 **무작위로 나눈 그룹의 차이보다 크거나 작은 경우**를 세어 **p-값** 계산

```python
def statistic(x, y):
    return np.mean(x) - np.mean(y)

def permutation_test(x, y):
    obs_diff = statistic(x, y)              # 표본의 평균 차이
    all = np.append(x, y)                   # 두 표본 합치기
    diffs = []
    np.random.seed(42)
    for _ in range(1000):                   # 1000번 반복
        idx = np.random.permutation(len(all))   # 전체 인덱스 섞기
        x_ = all[idx[:len(x)]]
        y_ = all[idx[len(x):]]
        diffs.append(statistic(x_, y_))
    less_pvalue = np.sum(diffs < obs_diff) / 1000
    greater_pvalue = np.sum(diffs > obs_diff) / 1000
    return obs_diff, np.minimum(less_pvalue, greater_pvalue) * 2   # 작은 쪽 × 2 (양쪽 꼬리)
```

- `np.random.permutation(n)`: 길이 n의 랜덤하게 섞인 인덱스 배열 생성
- 영가설을 기각하는 것이 목적이므로 두 p-값 중 **작은 값을 선택하고 2를 곱함**

| 비교 | 평균 차이 | p-값 | 결론 |
|---|---|---|---|
| 파이썬 vs C++ | 3.153 | 0.022 | p < 0.05 → 영가설 기각, **차이 있음** |
| 파이썬 vs 자바스크립트 (105권, 평균 15.53) | -0.784 | 0.566 | p > 0.05 → 영가설 기각 불가, **의미 있는 차이 없음** |

> 💡 사이파이 1.8 이상에서는 `stats.permutation_test()`로 직접 구현 없이 가능 (기본 9,999번 수행).
> ```python
> res = stats.permutation_test((python_books['대출건수'], cplus_books['대출건수']),
>                              statistic, random_state=42)
> print(res.statistic, res.pvalue)
> ```

## 전체 흐름 정리

1. 표준점수(z)와 중심극한정리로 **표본 → 모집단 추정**의 기반 마련
2. 신뢰구간으로 파이썬 도서의 **모집단 평균 범위** 추정
3. 가설검정(z 점수, t-검정)으로 **두 도서 평균 차이가 우연이 아님**을 확인 (파이썬 > C++)
4. 모집단 분포를 가정하기 어려우면 **순열검정**(비모수검정)으로 동일한 결론 확인
5. 자바스크립트와는 차이가 유의하지 않음 → 결론: 파이썬 도서의 평균 대출건수는 C++보다 높지만 자바스크립트와는 비슷함



## 02. 머신러닝으로 예측하기

<!-- 새롭게 배운 내용을 자유롭게 정리해주세요.-->
> 남산도서관 대출 데이터로 **도서권수(입력)로 대출건수(타깃)를 예측**하는 모델을 만들어 보며 머신러닝의 기본 흐름(훈련 → 평가)을 익힘. 진짜 미래를 예측한다기보다 샘플 데이터에서 알지 못하는 값을 예상하는 것.

---

## 머신러닝 기초 용어

### 머신러닝과 인공지능

- **머신러닝**: 컴퓨터 프로그램이 데이터에서 **패턴을 학습**하고, 학습된 패턴으로 새 데이터에 대해 빠르고 유용한 결정을 내리는 방법 (예: 스팸 메일 감지기를 스팸/비스팸 메일로 **훈련**한 뒤 새 메일을 예측)
- 인공지능의 **하위 분야**이며, 지도 학습과 비지도 학습으로 나뉨 (인공지능 ⊃ 머신러닝 ⊃ 지도·비지도 학습)
- 파이썬의 대표적인 머신러닝 패키지는 **사이킷런(scikit-learn)** (코랩에 설치되어 있음. 로컬은 `pip install scikit-learn`)

### 모델(model)

- 추상적으로는 **알고리즘 자체** (예: "선형 회귀 모델을 사용하겠다")
- 구체적으로는 머신러닝으로 **학습된 패턴을 저장하는 소프트웨어 객체** (사이킷런에서는 어떤 클래스의 인스턴스 객체가 모델)

### 지도 학습 vs 비지도 학습

| 구분 | 설명 |
|---|---|
| **지도 학습** | 각 샘플의 **정답(타깃)**을 알고 있는 경우. 입력과 타깃으로 훈련한 뒤, 타깃을 모르는 새 입력에 적용해 타깃을 예측 |
| **비지도 학습** | 입력만 있고 **타깃이 없는** 경우. 대표적으로 군집 알고리즘 (이 책에서는 다루지 않음) |

- **입력(input)**: 타깃을 맞추기 위해 모델이 재료로 사용하는 데이터
- **타깃(target)**: 정답
- **훈련(training)**: 입력과 타깃을 전달해 데이터의 패턴을 학습시키는 과정

> 💡 **딥러닝**은 별도 알고리즘 종류가 아니라 머신러닝 알고리즘 중 **신경망(neural network)**을 사용하는 경우를 부르는 말. 선형 회귀는 지도 학습 전용이지만, 신경망은 지도·비지도 학습 모두 가능.

---

## 훈련 세트와 테스트 세트

- 훈련에 사용한 데이터로 모델을 평가하면 **모델이 타깃을 외워버려** 100% 맞출 수 있어 의미가 없음 (시험 볼 때 정답을 알려주는 것과 같음)
- 그래서 전체 데이터를 두 개로 나눔

| 세트 | 용도 |
|---|---|
| **훈련 세트(training set)** | 모델 **훈련**에 사용 (입력 A, 타깃 A) |
| **테스트 세트(test set)** | 모델 **평가**에 사용 (입력 B, 타깃 B). 일반적으로 전체의 **20~25%** |

### `train_test_split()` — 훈련/테스트 세트 나누기

- 데이터를 **무작위로 섞은 뒤** 기본 **75% 훈련 / 25% 테스트**로 분할 (데이터 앞부분에 특정 성향이 몰려 있을 수 있어 섞어야 함)
- 분할한 두 세트를 리스트로 반환하므로 변수 두 개에 나눠 받음

```python
from sklearn.model_selection import train_test_split
train_set, test_set = train_test_split(ns_book7, random_state=42)
print(len(train_set), len(test_set))    # 282577  94193
```

> 📝 분할 비율은 `test_size` 매개변수(0~1)로 조정.

### 입력과 타깃 준비 — 2차원 배열 vs 1차원 배열

```python
X_train = train_set[['도서권수']]     # 열 하나를 리스트로 감싸 → 데이터프레임(2차원)
y_train = train_set['대출건수']       # 시리즈(1차원)
print(X_train.shape, y_train.shape)   # (282577, 1) (282577,)
```

- 사이킷런은 **입력은 2차원 배열, 타깃은 1차원 배열**을 기대함
- 관례상 2차원 배열(행렬)은 **대문자**(`X_train`), 1차원 배열은 **소문자**(`y_train`)로 표기
- 2차원 배열에서 **행 = 샘플, 열 = 특성(feature)**

## 선형 회귀 (연속적인 값 예측)

**선형 회귀(linear regression)**: 직선의 방정식으로 모델을 만드는 알고리즘. **회귀**는 타깃이 연속적인 실수인 문제.

```
y = a × x + b      (x: 입력, y: 타깃, a: 기울기, b: 절편)
```

- `fit()` 호출 시 데이터에서 학습하는 것이 바로 **기울기 a와 절편 b**

### 모델 훈련

```python
from sklearn.linear_model import LinearRegression

lr = LinearRegression()
lr.fit(X_train, y_train)       # 입력과 타깃을 전달해 훈련
```

### 결정계수 — `score()`

모든 사이킷런 모델이 제공하는 `score()`로 평가. 회귀 모델에서는 **결정계수(R²)**를 반환.

```
R² = 1 − Σ(타깃 − 예측)² / Σ(타깃 − 평균)²
```

- 보통 **0~1** 사이 값. 예측이 타깃의 평균 수준이면 **0**, 정확히 맞으면 **1**에 가까움 (평균보다 나쁘면 음수도 가능)
- 1에 가까울수록 입력과 타깃 사이 관계가 깊다고 볼 수 있음

```python
X_test = test_set[['도서권수']]
y_test = test_set['대출건수']
lr.score(X_test, y_test)       # 0.100 → 도서권수로 대출건수를 예측하기 어려움
```

## 로지스틱 회귀 (카테고리 예측)

### 회귀 vs 분류

| 구분 | 타깃 | 대표 알고리즘 |
|---|---|---|
| **회귀(regression)** | 연속적인 실수 | 선형 회귀 |
| **분류(classification)** | 카테고리(범주) | 로지스틱 회귀 |

- **이진 분류**: 두 개의 카테고리로 구분 (예: 스팸/비스팸)
- **다중 분류**: 세 개 이상의 카테고리로 구분 (예: 사진을 강아지/고양이/사람으로 구분)
- 분류에서 타깃 카테고리를 **클래스(class)**라 부름. 이진 분류에서 **0 = 음성 클래스, 1 = 양성 클래스** (양성이 "좋은" 클래스라는 뜻이 아니라 모델이 찾으려는 대상)

### 로지스틱 회귀 원리

선형 함수 결괏값 z를 **로지스틱 함수(시그모이드 함수)**에 통과시켜 0~1 사이 값으로 변환.

```
z = a × x + b
y = 1 / (1 + e^(-z))
```

- y > 0.5 → **양성 클래스**, y < 0.5 → **음성 클래스**로 예측

> 💡 다중 분류도 가능: 소프트맥스 함수 적용 또는 OvR(One versus Rest) 방식. 사이킷런의 `LogisticRegression`은 이진·다중 분류 모두 지원.

### 모델 훈련

타깃을 이진 분류에 맞게 변환 → 대출건수가 **평균보다 높으면 양성(1)**, 아니면 음성(0).

```python
borrow_mean = ns_book7['대출건수'].mean()
y_train_c = y_train > borrow_mean        # 불리언 시리즈 (True=1, False=0으로 자동 인식)
y_test_c = y_test > borrow_mean

from sklearn.linear_model import LogisticRegression
logr = LogisticRegression()
logr.fit(X_train, y_train_c)
logr.score(X_test, y_test_c)             # 0.7106 (정확도)
```

- 분류 모델의 `score()`는 **정확도(accuracy)** = 입력 데이터 중 정답을 맞힌 비율

### 클래스 불균형과 더미 모델

```python
y_test_c.value_counts()      # False 65337 / True 28856  → 음성 약 69%, 양성 약 31%
```

- 음성 클래스가 훨씬 많아, **무조건 음성으로 예측해도 69%** 정확 → 71% 정확도는 그다지 높은 값이 아님
- **더미(dummy) 모델**: 가장 많은 클래스(분류) 또는 타깃 평균(회귀)으로 무조건 예측. 모델의 **기준점** 역할
  - 회귀: `DummyRegressor` / 분류: `DummyClassifier`

```python
from sklearn.dummy import DummyClassifier
dc = DummyClassifier()
dc.fit(X_train, y_train_c)
dc.score(X_test, y_test_c)      # 0.6937
```

> 💡 더미 모델보다 점수가 낮지 않더라도 별 차이가 없으면 유용한 모델이라 보기 어려움. 클래스 비율이 균등하지 않으면 모델 성능을 자칫 잘못 해석할 수 있음.

| 모델 종류 | `score()` 반환값 |
|---|---|
| 회귀 모델 (선형 회귀) | **결정계수** |
| 분류 모델 (로지스틱 회귀) | **정확도** |
